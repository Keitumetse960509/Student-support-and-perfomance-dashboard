# Student-support-and-performance-dashboard

## About the Project

A data-driven project exploring factors that may influence student academic performance and identify areas where educational support can be improved.


## Project Objectives

- Explore factors that may affect students' access to education.
- Identify common challenges experienced by students.
- Organise and analyse student-related data.
- Present findings in a clear and understandable way.
- Develop recommendations that could help improve student support.

## Skills Demonstrated

- Sociology
- Research
- Data collection and organisation
- Data analysis
- Administration
- Documentation
- Data visualisation
- Report writing
- Problem solving

## Project Structure

- `data/` – datasets used in the project
- `analysis/` – data analysis and findings
- `reports/` – project reports and recommendations
- `documentation/` – project notes and supporting information

## Future Development

The project will be expanded by creating a sample dataset, analysing the information, creating visualisations, and developing recommendations based on the findings.
